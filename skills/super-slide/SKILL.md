# Super Slide — 全景信息型幻灯片设计师

## 1. 设计哲学

传统幻灯片只服务"演讲态"（30%）：大字少字留白多。
Super Slide 同时服务**阅读态（70%）**，不拆页、不丢细节。

### 核心原则

| 原则 | 含义 |
|------|------|
| **全景单页** | 一个主题 = 一页幻灯片。只按概念组拆页，不按内容体积拆页 |
| **三级入口** | L1锚点(最大字号+品牌色) → L2结构(卡片+色标) → L3证据(小字+来源)，同页共存 |
| **视觉补偿** | 内容稀疏时用设计元素填空白，而非扩张间距（技法库见 references/visual-compensation.md） |
| **色调主导** | 一色定调(~70%)，一色点睛(~20%)，中性托底(~10%) |
| **微间距** | 压缩组件间距(8-12pt)但不压缩视觉呼吸(标题区24-32pt) |

### 双态工作流

```
演讲态 (30%) ──── 听众从 L1 锚点进入，目光沿结构区扫描
                      │
阅读态 (70%) ──── 读者从 L1→L2→L3 逐层深入，信息自包含
```

## 3. 模板系统（外挂）

视觉风格不写在 SKILL.md 中，由外挂模板包提供。

### 3.1 模板索引

所有可用模板在 `templates/index.json` 中注册。结构规则（本文件第4节）对所有模板通用，只有视觉token（颜色/字体/间距/圆角）由模板包决定。

### 3.2 模板包结构

```
templates/<模板ID>/
└── design-tokens.json     ← 唯一视觉token文件
```

### 3.3 使用方式

制作slide前，先读取 `templates/index.json` 获取全部可用模板列表，根据用户需求选择。

当前可用模板见 `templates/index.json` 的 `templates[]` 数组。每个模板独立包含完整的视觉 token（颜色/字体/间距/布局模式），互不依赖——**加模板 = 只加文件，不动 SKILL.md**。

## 4. 内容分析框架（三级入口）

### 4.1 L1 — 锚点

每个slide必须有一个视觉锚点：一个数字、一个命题、一个核心主张。

| 属性 | 规格 |
|------|------|
| 字号 | 28-36pt |
| 权重 | Bold |
| 颜色 | 品牌主色 |
| 位置 | 左上→中上（Z字阅读起点） |

### 4.2 L2 — 结构

slide主体，承载"在讲什么"。用卡片网格组织。

| 规则 | 说明 |
|------|------|
| 卡片数量 | 最多10张/页，超出行数拆组而非拆页 |
| 卡片网格 | 6列微网格，12pt间距 |
| 颜色编码 | 用强调色标记不同类别 |

### 4.3 L3 — 证据

细节、来源、数据备注。用小字在卡片内或底部区域呈现。

| 规则 | 说明 |
|------|------|
| 字号 | 7-8pt |
| 颜色 | 次级文本色 |
| 位置 | 卡片底部或页面底部脚注区 |

## 5. 布局决策系统

| 内容类型 | 推荐布局 |
|---------|---------|
| 单一大主张 | 左上锚点 + 右侧展开 |
| 多要点(3-6) | 2×3 或 3×2 卡片网格 |
| 数据表格 | 卡片内嵌表格，交替行色 |
| 流程/管线 | 水平箭头流，节点带色标 |
| 对比/二分 | 50/50 分屏，左主导右辅助 |
| 架构图 | 引用 architecture-diagram 生成SVG后嵌入 |

## 6. 技术实现规则

### 6.1 画布与结构

```html
<body>
<div class="slide">       <!-- 单页滑动容器 -->
  <div class="safe">       <!-- 安全边距 24pt -->
    <div class="zone-anchor">  <!-- L1 锚点区 --></div>
    <div class="zone-structure"><!-- L2 结构区 --></div>
    <div class="zone-evidence"> <!-- L3 证据区 --></div>
  </div>
</div>
</body>
```

### 6.2 CSS 约束

| 特性 | 状态 | 说明 |
|------|------|------|
| 背景 | 仅限 div | 不支持文本元素上的背景 |
| 边框 | 仅限 div | 文本元素用下划线代替 |
| 渐变 | ❌ 不支持 | 预渲染为PNG嵌入 |
| SVG | ❌ 不支持 | 预渲染为PNG或作为占位符 |
| 阴影 | box-shadow 仅限 div | 不支持 text-shadow |
| Flexbox | ✅ | display: flex 推荐 |
| Grid | ✅ | display: grid 推荐 |

### 6.3 文本标签规则

**所有文本必须在 `<p>`、`<h1>`-`<h6>`、`<ul>`、`<ol>` 标签内。**

- ❌ `<div>文字</div>` → PPT转换时消失
- ✅ `<div><p>文字</p></div>`
- 列表必须用 `<ul>/<ol>`，不要手动输入 •、-、* 等符号

### 6.4 字体

使用模板包 `design-tokens.json` 中定义的字体。
后备字体为 `Arial, Helvetica, sans-serif`。

## 7. 工作流

1. **读取模板**：打开 `templates/index.json`，根据用户需求选择模板
2. **分析内容**：识别 L1 锚点、L2 结构、L3 证据
3. **选择布局**：根据内容类型匹配第5节布局
4. **生成HTML**：按第6节规则产出HTML
5. **可选配图**：如需架构图，引用 architecture-diagram 技能生成后嵌入
6. **验证**：对照质量表检查
