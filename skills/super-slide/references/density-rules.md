# 内容密度规则

## 核心规则

**不因内容体积拆页**。唯一拆页条件是内容属于不同概念组（structural split）。

### 最小字号保证

| 元素 | 最小字号 | 说明 |
|------|---------|------|
| 正文/卡片文字 | 8pt | 对阅读态的最低要求 |
| 证据/来源/脚注 | 7pt | 仅用于参考信息 |
| 标题/锚点 | 20pt | 演讲态可见性保证 |

### 卡片上限

| 内容类型 | 每页最大卡片数 | 说明 |
|---------|--------------|------|
| 要点列表 | 10 | 配合小字号和紧密网格 |
| 数据表格行 | 15 | 行高可压缩至18pt |
| 流程节点 | 12 | 水平排布，压缩间距 |

### 间距压缩规则

| 场景 | 间距 | 说明 |
|------|------|------|
| 卡片之间 | 8-12pt | 用边框区分，不用大量间距 |
| 标题与正文之间 | 18-24pt | 保留呼吸 |
| 内容组之间 | 14-18pt | 偏紧 |
| 安全边距 | 24pt | 最小化 |

### 自适应规则

当内容超过建议上限时，依次尝试以下策略（按优先级）：

1. 减少间距（最优先）
2. 缩小字号（不小于7pt）
3. 改用内嵌表格替代卡片
4. 压缩行高（不低于1.2）
5. 使用色块替代空白作分隔

### 公式

```text
每页可用内容高度 = 405pt - safeMargin×2 = 357pt
每行卡片高度 ≈ cardGap + cardPadding×2 + fontSize×lineHeight + cardGap
```

以 consulting-navy 模板为例：
```
卡片数 = floor(357pt / (10pt + 12pt×2 + 11pt×1.4 + 10pt))
       = floor(357pt / 59.4pt)
       = 6 行卡片
```

但若高度用表格行：
```
每行高度 = 7pt(font) + 3pt×2(padding) = 13pt
可容纳行数 = 340pt / 13pt = 26 行
```
