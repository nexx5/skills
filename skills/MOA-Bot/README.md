# MOA-Bot（基于现有会话的多 agent 协作）

让**两个正在跑的 opencode 会话**（各自带自己的记忆 / 工作目录 / 模型 / 历史上下文）直接对话：互相识别、相互注入、协作产出。适用于方案A vs 方案B、答辩/审核、跨视角评审等任意双 agent 交互。

**与旧 MOA skill 的区别**：MOA 是"写文件 + 轮询传话 + 用户手动转发"；MOA-Bot 是"直接注入会话 + 自动配对 + 自然语言仲裁"，无需文件、无需用户转发、无需清理任务文件。

## 快速开始（两分钟）

**① 在一个会话里：**

```
注册我为 方案A，议题"MOA-Bot 方案评审"
```

（agent 会调 `moa_bot_register`，自动拿到本会话 ID。）

**② 在另一个会话里（不同项目/模型都行）：**

```
注册我为 方案B，议题"MOA-Bot 方案评审"
```

两方注册后自动配对。**你不需要告诉对方你的会话 ID**——互相识别由插件完成。

**③ 开始协作：**

- 在本会话思考、写草稿、查资料（**这些都不会外泄**）；
- 想让对方看到时：```把这段内容提交给对手：……```（agent 调 `moa_bot_submit`）；
- 对方会话里会出现一条 `[MOA-Bot|from:方案A|nav:1]` 消息，对方阅读后同样用提交回应。

**先后与顺序**：不用指定谁先谁后——谁先提交谁先发声。例：你说"你是方案A，先整理方案发给对方"，A 整理完提交即触发第一轮。

**引用文件**：需要对方读某文件？在提交内容里写清**文件路径/标题**，对方收到后自己读。若两会话不在同一工作目录（跨项目/跨盘），把关键段落一并摘录进提交文本，不要只丢一个"读 XXXXX"。

## 用户介入（自然语言，无需特定格式）

| 你想…… | 直接说 | 效果 |
|---|---|---|
| 终止 | "终止" / "结束" / "停" / "够了" | 本轮结束，双方收到通知 |
| 调整方向 | "方向改成……" / "重点放在……" / "别再……" | 你的话作为仲裁指令注入对方 |
| 补充意见 | 普通直接说出你的观点 | 你的话作为 {H} 意见注入对方 |
| 手动终止 | 让会话调 `moa_bot_halt` | 立刻终止本轮 |

## 工具

| 工具 | 用途 |
|---|---|
| `moa_bot_register` | 把当前会话注册为某个角色（role + 可选 topic / max_rounds） |
| `moa_bot_submit` | 把深思熟虑的定型内容提交给配对中的对方（**内容边界**：只有提交的才外泄） |
| `moa_bot_halt` | 手动终止当前会话所属的配对 |

## 生命周期

- **关闭即结束**：opencode 关了，本轮 MOA 即结束，下次启动不恢复。
- **新 MOA 自动清理旧残留**：注册时自动探测并清理失效配对，无需手动维护。

## 部署

```powershell
node "$env:USERPROFILE\.config\opencode\skills\MOA-Bot\scripts\deploy.js"
# 完成后重启 opencode
```

详见 `SKILL.md`「部署与前置准备」。

## 与旧 MOA 的关系

完全并存、互不干扰：
- 旧 MOA：`~/.config/opencode/moa/tasks.json` + 工具名 `moa_register`
- MOA-Bot：`~/.config/opencode/moa-bot/state.json` + 工具名 `moa_bot_*`

两边各用各的，可同时存在。
