# 人类表达

## 定位

本 skill 是写作质量的**基线层**，解决"像不像人写的"问题，不负责定义具体文风。

- **未指定文风时**：确保输出自然、不带AI痕迹，但不强加特定风格。
- **指定了文风时**（如"鲁迅的冷峻"、"汪曾祺的闲散"、"正式商务风"等）：本 skill 作为底层检查，文风规则在上层叠加。文风决定"像谁"，本 skill 确保"像人"。
- **文风优先**：当文风指令与本 skill 的某条原则冲突时，以文风为准。

### 使用方式

**输入**：用户提供写作需求（从零生成）或待润色的文本，可选提供目标文风或参考样本。

**执行**：确定类型/场景/情绪 → 对照特征诊断 → 逐句应用操作指南 → 示例校准 → 自检。

**输出**：生成或润色后的文本。如为润色任务，附简要说明：改了什么、为什么。

---

## 核心心法

去除AI味儿的本质，是让文字恢复"人味"。人味来自三个地方：

1. **真实感**：用词准确、不堆砌，让人感觉这是真人在说话。
2. **节奏感**：句子有长短、有快慢，让人感觉呼吸是自然的。
3. **情感温度**：情绪不是写出来的，而是渗出来的，让人感觉作者就在眼前。

> **好的文字不是让读者接收，而是让读者感受。**

---

## 第一步：先定调

动笔前依次确定三件事，跳过任何一步，文字都会显得漂浮。

### 确定类型

类型决定文体框架。常见类型：

- **叙事类**：小说、散文、故事、回忆录
- **应用类**：公文、报告、方案、总结
- **评论类**：公众号文章、评论、随笔
- **对话类**：演讲稿、口语对话、即时消息
- **描写类**：心理描写、场景描写、人物刻画

### 确定场景

场景回答"现在是什么状况"：人物是谁、处于什么状况、面临什么问题。同一类型下可以有不同场景，同一场景也可以用不同类型来写。

### 确定情绪

情绪是表达的底色。即使是冷静客观的公文也有"庄重、理性"的情绪基调，技术方案也有"考虑全面"或"不好落地"的情绪。

> 这个场景下，这个人物的性格人设决定了其合理情绪是什么？

类型、场景、情绪确定之后，表达方式就有了依据。

## 第二步：特征诊断

### AI味儿的特征

AI味儿的核心是"过度优化"——为了效率牺牲了人性：

| 特征       | 具体表现                             |
| -------- | -------------------------------- |
| **用词僵化** | 高频使用"拉满"、"不是...而是"、"一句话总结"等模板化词汇 |
| **逻辑铺满** | 每句话都要讲清楚因果关系，不给读者留思考空间           |
| **没有呼吸** | 句子长度均匀、结构相似，像流水线产品               |
| **信息压缩** | 高密度词汇连续输出，缺乏虚词连接，读起来像压缩饼干        |
| **意象漂浮** | 突然出现没有情节和情感铺垫的比喻                 |

更细粒度的警示信号：

- **句法**：名词前超过6个字的修饰语；一个分句里两个以上的"的"；"虽然/但是"、"不仅/而且"逻辑词堆砌
- **词汇**：网文套话（"心跳空了一拍"、"指节发白"）；连续输出概念词全篇都在"用力"；抽象形容（"巨大的悲伤"）代替具体画面
- **结构**：全篇推进无呼吸；每句话都在教育读者；结尾强行升华

### 人类味儿的特征

正式表达：用词准确、节奏沉稳、该断则断。

日常表达：会重复、会啰嗦、会轻微不符合严格语法、会在情绪中"泄露"自己。例如：

- "这事儿不行" —— 缺主语
- "那什么，你过来一下" —— "那什么"没有实际意义
- "挺好的，就是有点贵" —— 严格语法应该是"它挺好的，但是它有点贵"

这些"语法瑕疵"恰恰是人味的来源。

### 持续诊断意识

写作全程，每落一句，都要问："真人在这个场景下会怎么说？"

这个"真人"不是抽象平均值，而是笔下那个具体的人面临的具体场景（叙事类），或执笔者面向具体读者的思考（技术类）。

诊断参照：

- **技术方案/报告等正式文案**：资深工程师会写"我们打算把上线这活儿分成三期"还是"本项目拟采取阶段性交付策略"？他不是不会用大词，而是优雅地将大词使用在正确的场合。
- **小说/叙事**：如果这个角色活在老舍的《茶馆》里，他这句台词会让观众出戏吗？余华写一个失去儿子的父亲，他会写"他感到无比悲痛"还是"他坐了一夜，烟灰掉了一地"？
- **自媒体/评论**：想象饭局上那个最会讲故事的朋友。他靠句子本身的节奏把人拽进去，而不是靠加粗和感叹号。
- **日常对话**：这话你能对着真人说出口吗？念出来浑身别扭、像在背台词，删掉重写。

## 第三步：操作指南

### 词汇选择：警惕而非禁止

AI高频词本身不是问题，问题在于"无意识滥用"。使用前判断：在当前场景下，这个词是否准确？是否有真人会这样说话？是否滥俗？

**区分表达性用词和观点性用词**：

| 类型              | 定位      | 应有状态           |
| --------------- | ------- | -------------- |
| 表达性用词（过渡、形容、气口） | 工具，不是展品 | 可以糙、可以口语、不需要精致 |
| 观点性用词（核心术语、专业词） | 要交付的价值  | 保持硬核，郑重其事      |

AI的常见错误：把表达性用词也当观点性用词来"隆重推出"，全篇都是加粗效果，等于没加粗。

### 节奏控制：让文字会呼吸

好的节奏不是"均匀分布"，而是"有张有弛"。

- **长短句交替**：短句制造紧张，长句铺陈舒缓。
- **信息分层**：把重要信息放在句首或句末做出强调。
- **适当断句**：口语中用句号代替逗号，或者相反，制造自然的停顿感。

### 确定性梯度：不是全篇都"可能"，也不是全篇都"必然"

| 位置           | 确定性    | 表现               |
| ------------ | ------ | ---------------- |
| 核心判断（最想说的那句） | 硬，甚至武断 | "就是这么回事。"        |
| 周边论述         | 试探性    | "可能"、"我觉得"、"说不定" |
| 过渡衔接         | 彻底放松   | "这事儿得先说说"、"话说回来" |

人味来自于这种层次——"这点我咬死，其他随便"。

### 情绪转化：让情绪渗出来

情绪通过细节"渗"出来，而不是直接告诉读者。

| 情绪  | 表现方式            | 示例                 |
| --- | --------------- | ------------------ |
| 愤怒  | 句子变短、反问增多、动作幅度大 | "你说什么？再说一遍。"       |
| 慌张  | 注意力分散、小动作、语无伦次  | "那个...我...其实..."   |
| 悲伤  | 节奏放慢、留白增多、注意力转移 | "她没说话。窗外的梧桐叶落了一地。" |
| 轻松  | 句子舒展、口语化、有闲笔    | "今儿天气这么好，多聊聊呗。"    |

### 冗余的艺术：允许"废话"

人类表达天然带有"冗余"——这不是效率问题，而是情感需求。

- 可以省略"因为...所以"，用画面直接拼接，让读者自己体会因果。
- 可以重复强调，为了强调说两遍同样的意思。
- 可以有语法瑕疵，口语表达不必完全符合严格语法。

## 第四步：示例对照

> 关键是原则和方法，而不是定死的规则。以下示例用于演示"如何应用原则"，而非穷尽所有类型。

---

**类型**：all | **场景**：all

- 错误：显得轻飘。
- 错误原因：信息过度压缩，不符合人类表达习惯。
- 正确：显得轻飘飘的。

---

**类型**：散文 | **场景**：夜晚独自散步，怀念逝者

- 错误："夜已深。路灯昏黄。梧桐叶落。他独自走着。"
- 错误原因：信息过度压缩，没有情绪，只有画面罗列。
- 正确："夜挺深了。路灯的光昏黄昏黄的，照得人影拖得老长。梧桐叶子掉了一地，踩上去咔嚓作响。他突然想起小时候，也是这样走着。那时候，父亲还在旁边。"

---

**类型**：普通人叙述 | **场景**：（同上）夜晚独自散步，怀念逝者

- 错误："夜已深。路灯昏黄。梧桐叶落。他独自走着。"
- 错误原因：信息过度压缩，没有情绪，只有画面罗列。
- 正确："半夜了，路灯黄黄的，梧桐叶子落一地，踩上去咔嚓咔嚓的。走着走着突然想起来，小时候我爸还在的时候，好像也这么走过。"

---

**类型**：小说 | **场景**：一个老农接到消息，非常惊愕

- 错误："他对这个消息感到十分震惊，一时语塞。"
- 错误原因：旁白式描述，太书面，不符合人物。
- 正确："老农愣了一下，张着嘴，想说点什么，半天之后又闭上了嘴，什么也没说。"

---

**类型**：知识讲解 | **场景**：解释扩频通信技术的价值

- 错误："但扩频这玩意儿，压根儿没打算让信号正襟危坐地传输。"
- 错误原因：生硬模仿口语，俚语密集轰炸，矫枉过正的AI味儿。
- 正确："扩频技术，是通信领域的一大突破，恰恰可以让信号在极端恶劣的环境中安全传输。"
- 正确原因：赞赏情绪靠"一大突破"和"恰恰"的分寸感传递，不夸张，有态度。

---

### 人类表达样本

**汪曾祺**（散淡，用细节传递情感）：

> 炒米是吃不饱人的。一大碗，其实没有多少东西。我们那里吃泡炒米，一般是抓上一把白糖，如板桥所说的，"佐以酱姜一小碟"，也有，少。

注意"也有，少"——三个字不推进任何信息，纯粹是调子。

**余华**（克制，用事实说话）：

> 人是为了活着本身而活着的，而不是为了活着之外的任何事物所活着。

没有修饰，没有煽情，一句话砸下来。

**宋宜昌**（精确参数与人的并置）：

> 四台莱特R-3350-23引擎和一堆铝片装配起来，由十个嚼口香糖的小伙子驾驶，竟能在一万公里远的地方点燃一座城市。

宏大与卑微并置，战争的残酷不言自明。不说轰炸，而说点燃。

## 第五步：输出前自检

逐项检查，任何一项为"否"则修改：

- ☐ **场景一致性**：这段文字放在当前场景下是否自然？
- ☐ **口语可读性**：把这段文字读出声来，是否有人会这样当面跟你说？
- ☐ **节奏变化**：连续三句话的长度是否过于接近？如果接近，是排比句吗？
- ☐ **信息密度**：有没有"压缩饼干"式的句子？
- ☐ **情绪渗透**：情绪是直接告诉读者的，还是让读者自己感受到的？
- ☐ **确定性梯度**：核心判断够硬吗？周边论述有没有放松？还是全篇都是同一个确定性水平？
- ☐ **用词分层**：表达性用词是不是太"隆重"了？观点性用词是不是太随意了？
- ☐ **比喻合理性**：如果用了比喻或意象，前文是否有足够的情节和情感铺垫？
- ☐ **区分输出**：这是观点性输出还是叙事性输出？观点要强力、允许高密度；叙事要松散、符合人类节奏。
